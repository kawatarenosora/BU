# BU [agent] - 手動バックアップ / リストア mod

Project Zomboid B42.21 用の JavaAgent mod。ホットキーで現在のセーブをバックアップし、タイトル画面からリストアします。

PZ のオートセーブは一定間隔で動くため、ディスク上に最新にあるセーブが必ず望んだ状態であるとは限りません。本 mod は自分で任意に起動するバックアップを足し、戻せる既知の正常コピーを確保できるようにします。

> [!NOTE]
> 本 mod の Java 部分（bu-agent）は `-javaagent` での指定が必要です。サブスクライブだけでは有効化されません。

- 対応: Build 42.21 / modversion 0.5.0
- 動作: クライアント側のみ。サーバーへの導入は不要です
- シングルプレイと MP ホストで動作します。MP クライアントでは無効です（ローカルセーブが存在しないため）
- 英語のみ。UI 文言はゲーム側の翻訳システムを経由せずハードコード。因此、ゲームの言語設定に関わらず常に英語で表示されます

## 操作

1つのキーで両方を担います。既定は `F6` で、Mod オプション（`[BU]`）から変更できます。

| 場面 | 動作 |
| --- | --- |
| ゲーム中 | 手動バックアップ |
| タイトル画面 | リストアリストの開閉 |

バックアップはゲーム中のみ、リストアはタイトル画面のみで動作するため、同じキーが衝突することはありません。

### バックアップ（ゲーム中）

1. キーを押します。ゲーム速度を 0 に落とし、オートセーブを（ベストエフォートで）抑止します。
2. ワールドを保存したうえで、セーブフォルダをバックアップ先へコピーします。
3. ハロー通知で結果を通知します。

> [!TIP]
> キーを押す前に ESC メニューを開いておくと最も安全です。すでにポーズ中なので、コピー中にセーブへ書き込みが入る余地がありません。

### リストア（タイトル画面）

1. キーを押してリストを開きます。項目は更新順（新しい順）に並び、1 ページに 8 件表示します。
2. スロットをクリックすると選択されます（ボタンが確定表示に切り替わります）。
3. 8 秒以内に同じスロットをもう一度クリックすると確定します。リストアはライブセーブフォルダを上書きします。

スクロールではなくページングとしているのは、ウィンドウの高さを一定に保ち、画面外にはみ出すことが無いためです。

## バックアップの保存場所

```text
<user.home>/Zomboid/BU/<mode>__<saveName>\
```

| プラットフォーム | 実際のパス |
| --- | --- |
| Windows | `C:\Users\<あなた>\Zomboid\BU\` |
| macOS | `/Users/<あなた>/Zomboid/BU/` |
| Linux | `/home/<あなた>/Zomboid/BU/` |

- root は Java の `user.home` から取得しているため、全プラットフォームで同じフォルダに解決されます。macOS と Linux（ネイティブ、Proton のどちらでも）は問題ありません。
- **これはゲーム側のセーブルートの中で、外側ではありません。** `Sandbox/`、`Multiplayer/`、`mods/` と並びます：

```text
~/Zomboid/
  Sandbox/     ゲームのセーブ
  Multiplayer/
  mods/
  BU/          <- 本 mod のバックアップ（← ここ）
```

- ゲーム内でセーブを削除した場合、削除されるのは `~/Zomboid/Sandbox/<セーブ名>` だけなので、バックアップは残ります。**ただし `Zomboid` フォルダごと消すと（再インストール、クリーンインストール手順）バックアップも消えます。** 気になる場合は `BU` フォルダを別の場所へコピーしてください。
- **セーブごとに固定スロット 1 つ**です。タイムスタンプの世代は持ちません。同じワールドを再バックアップすると自分のスロットを上書きするので、「最後に正常だった 1 コピー」がワールドごとに 1 つだけ残り、古いコピーを整理する必要がありません。
- 書き込みは必ず `tmp` → 検証 → 差し替えの順です。失敗や中断しても直前の正常コピーが壊れることはありません。差し替えは同一ボリューム内の rename です。

## オプション

タイトル画面の Mod オプションで変更します。

| オプション | 既定値 | 内容 |
| --- | --- | --- |
| 通知を表示 | オン | バックアップ / リストアの進捗をハロー通知とログで表示します |
| 手動キーを有効化 | オン | 手動キーを有効化します。ゲーム中はバックアップ、タイトル画面ではリストアリストの開閉 |

## 必要条件・導入手順

### jar の場所（Workshop 購読時）

```text
<Steamライブラリ>\steamapps\workshop\content\108600\<WORKSHOP_ID>\mods\BU\42.21\agent\bu-agent.jar
```

※ `<Steamライブラリ>` は環境で異なります（デフォルトは `C:\Program Files (x86)\Steam`）。
確認方法：Steam「設定 → ストレージ」のライブラリフォルダ、またはゲームのプロパティ → 「インストールファイル」 → 「参照」。

### Windows の方（推奨）：ランチャーを使用

JVM オプションの手編集も jar のコピーも不要です。[PZ-JAM-Launcher](https://github.com/kawatarenosora/PZ-JAM-Launcher) で上記 jar の場所を指定するだけで起動できます。

### Windows の方（手動設定）

1. エクスプローラーで `C:\` を開き、新しいフォルダーを作成して名前を `PZAgents` にしてください（`C:\PZAgents` になります）。
2. ゲームを終了し、上記 jar を `C:\PZAgents` にコピーしてください。
3. ゲームフォルダの `ProjectZomboid64.json` をバックアップし、既存の `vmArgs` 配列の中に以下を1行追加してください（前後のエントリとのカンマ区切りに注意。配列全体の置換は不要です）。

```json
"-javaagent:C:/PZAgents/bu-agent.jar"
```

※ 別のフォルダを使いたい場合はパスの該当部分を読み替えてください（分かる人向け）。

### macOS / Linux の方（手動設定）

1. ホームフォルダに `PZAgents` フォルダを作成し、上記 jar をコピーしてください。
2. Project Zomboid のプロパティ → 「起動オプション」に以下を追加してください（末尾の `--` も忘れずに）。

```text
-javaagent:"~/PZAgents/bu-agent.jar" --
```

※ 別のフォルダを使いたい場合はパスの該当部分を読み替えてください（分かる人向け）。

## 確認・更新・削除

- 起動ログに `[BU-Agent] loaded rev=...` と `[BU] core loaded v...` が出ることを確認してください。ブリッジが見つからない場合は `BU.Debug()` が `bridge=false` を出すので、`-javaagent` が読み込まれていません。
- jar 自体の更新はワークショップ更新履歴で告知します。手動設定の方は告知後に再コピーしてください（ランチャー使用の方は再設定不要です）。
- 無効化時は mod 無効化後に上記引数だけを除去してください。
- ※ サーバーへの導入は不要です（クライアント側のみ）。

## 注意

- Java エージェントがフックするゲーム側のメソッドは 1 つだけ（`LuaManager$Exposer.exposeAll`）で、これはバックアップブリッジを Lua へ公開するためだけのものです。バックアップ本体は素の `java.nio` によるファイルコピーなので、特定のゲームビルドに依存しません。
- バックアップ中のポーズとオートセーブ抑止はベストエフォートです。コピーの最中に書き込みが入る可能性を下げる働きにはなりますが、セーブファイルに対するハードロックではありません。
- ファイルが一時的にロックされている場合（ゲームが保持している大きめの `map_*.bin` など）、コピーは一時エラーとして返り、3 秒間隔・最大 60 回（約 3 分）まで再試行します。それでも成功しない場合はその実行を中断し、直前の正常バックアップはそのまま残ります。
- リストアは同期実行です。タイトル画面にはバックグラウンドコピーを駆動する tick ポンプが無いためです。コピー中は UI がフリーズしますが、これは意図した挙動であり、同時に別の処理が始まってしまうことも防ぎます。
- リストアはライブセーブフォルダを置き換えます。そのワールドにクライアントが接続している状態では実行しないでください。
- 世代を持たないため、リストアするとスロットの中身が上書きされます。残しておきたい場合は先にスロットを別へコピーしてください。

## 動作確認（Lua コンソール）

```lua
-- ブリッジ・バックアップ先・スロット一覧・現在のセーブを表示
BU.Debug()

-- 手動バックアップを実行（ホットキーと同じ経路）
BU.doBackup(true)

-- スロット名でリストア（"<mode>__<saveName>" 形式）
BU.doRestore("Sandbox__MyWorld")

-- コンソールからリストアリストを開き直す
BU.Reopen()

-- 停止した実行を強制解除（書き込みなし。強制終了後の後片付け用）
BU.Abort()

-- リストアリストのウィンドウ状態を出力
BU.WinState()
```

```text
agent/src/            bu-agent ソース（ByteBuddy フック）
```

## エージェントのビルド

JDK 25 のツールチェーンが必要です。

```powershell
gradle -p agent clean shadowJar -PbuRev=<tag>
```

`-PbuRev` の値は `bu/build-info.properties` に展開され、起動時に `[BU-Agent] loaded rev=<tag>` として出力されます。省略すると `unversioned` になります。

## クレジット・謝辞
